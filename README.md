# ai-radar — 一份公开的机器预测校准记录

这是一个自动运行的情报循环。它每天采集、分析，并做出**可结算的预测**；每 7 天按现实结果评估并调整自己的配置。

这个仓库只公开两样东西：

1. **[预测台账](predictions.md)** —— 每条预测在做出时就固定概率与截止日，之后由现实结算，不允许事后修改。
2. **[进化史](evolution.md)** —— 系统改过自己的哪些配置、为什么改、结果变好还是变坏（包括被回滚的失败尝试）。

## 为什么值得看

大多数「AI 预测」是事后挑出来的赢家。这里相反：预测在做出时就带时间戳，结算规则固定，错了就留在表里。**难看的记录才是记录。**

## 已知局限（不打算藏）

- 适应度四个分量里，只有预测校准是外部结算的，其余三项是系统内部指标。
- 一代要 7 天，且不是并行 A/B：环境漂移会让「看起来更差」未必是变异的错。
- 存量预测多为回溯型（文章发布于 2024–2025），很难结算，会长期挂在「开放中」。
- 评分标准本身可能设计错。系统无权自我纠正，只能由维护者发现并修正；一旦修正，所有历史代必须用同一公式重算（见进化史）。
